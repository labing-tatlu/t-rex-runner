# T-Rex Runner - Docker + Nginx deployment

The application itself is based on the open-source *T-Rex Runner* game.
The main goal of this repository is not the game, but the *infrastructure setup* around it.

---

# Project goals

- Run a static web application inside a Docker container
- Serve static files using Nginx
- Expose the service via a configurable port
- Access the application remotely using a VPN network (Tailscale)
- Practice clean and minimal infrastructure configuration

---

# Tech stack

- Docker Compose
- Nginx (Alpine)
- Static HTML / CSS / JavaScript
- Git / GitHub
- Tailscale (for remote access testing)
